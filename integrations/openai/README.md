# WCP tools for the OpenAI API

WCP capabilities as OpenAI function-calling functions.

**Worked-example domains:** industrial-maintenance, healthcare-logistics.

## Install

```bash
pip install openai wcp-sdk
```

See `wcp_tools_openai.py` docstring for the canonical usage loop. Tools exposed match the Anthropic, Gemini, and LangChain integrations: discover, post, subscribe, audit.
